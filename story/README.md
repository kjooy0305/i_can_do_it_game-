# 스토리 폴더

게임 "끝에 도달하는 이야기"의 이야기를 쓰는 곳이다. 세계관 노트(`world/`)가 "무엇이 정해졌나"를 모아 둔 곳이라면, 이 폴더는 "그것으로 어떻게 이야기를 쓰나"를 적는 곳이다.

## 표기 약속
- **【핵심】** 사용자가 직접 정한 것. 바꾸지 않는다.
- **【제안】** Claude가 덧붙인 초안. 마음에 안 들면 바꾸거나 지운다.
- **【미정】** 아직 정해지지 않은 것. 답이 나오면 【핵심】으로 옮긴다.

## 작업 순서 (1차: 평민 이야기)
1. 규칙서를 읽고 틀린 곳, 빠진 곳을 고친다.
2. 국가 3개의 분위기를 고친다. (지금 단계)
3. 국가마다 평민 이야기 씨앗을 골라 한 편씩 써 본다.
4. 써 본 이야기에서 규칙서에 없던 규칙이 생기면 규칙서에 옮긴다.
