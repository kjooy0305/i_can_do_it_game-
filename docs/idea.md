# 끝에 도달하는 이야기 — 아이디어 설정

텍스트 기반 선택형 인생 시뮬레이션. **태어나는 것에서 시작해** 한 달씩 자라며, 멸망해 가는 세상에서 선택을 이어 간다.
큰 틀은 "80억 분의 1"처럼 선택지가 아주 많고, 선택이 몸과 특성에 따라 달라진다.

참고: [1in8b.life](https://1in8b.life/ko/) (0세 출생 → 결정 앞에서 멈춰 선택, 상태·가족·인생 기록),
[project-moon-life](https://project-moon-life.cityborn.workers.dev/) (태어난 집안·배경, 의체·신체 손실 같은 특성이 쌓이는 방식)

## 홈
| 메뉴 | 내용 |
|---|---|
| 게임 시작 | "태어나기" (기본 / 커스텀 탭) → 0세부터 시작 |
| 이어서 하기 | 저장된 게임 불러오기 (자동 저장 1 + 수동 저장 여러 칸) |
| 사전 | 몬스터·장비·변이·지역·**특성** 도감. 각 탭은 **목록 → 상세** 화면. 저장을 단단히 해야 함 (아래 "저장" 참고) |
| **업적** | 달성·진행·숨김 업적. 데이터로 추가 가능 (사전과 설정 사이) |
| 설정 | 저장 · 시간 · 전투 · 화면 · 소리 · 데이터. 기능은 적당히 |

## 시간과 성장
- 게임 시간은 **일이 아니라 달(月) 단위**. 한 번의 결정(또는 한 번의 진행)이 한 달이다.
- **특별한 이벤트가 없는 달은 멈추지 않고 자동으로 넘어간다.** 넘긴 달은 로그에 한 줄로 요약(`3세 1~4개월 · 특별한 일 없이 지나감 · 허기 +12`)하고, 허기·돈 같은 자원 변화만 반영한다. 선택이 필요한 사건이 있는 달에서만 멈춘다. (설정에서 끌 수 있음)
- 표시는 `3세 5개월`, 멸망 이후 경과는 `멸망 +5개월`. 달이 지나면 허기가 차오른다.
- 태어날 때부터 성장한다. 나이에 따라 할 수 있는 선택이 달라진다 (유아: 울기·걸음마·기어가기 / 성인: 거래·전투·이식 등).
- **멸망이 시작되는 때** (게임 시작 때 하나를 고른다)
  1. **태어나기 전부터**: 이미 무너져 가는 세상에서 태어난다 (0세 = 멸망 +0)
  2. **유아기부터 (3세)**: 평범하게 태어나 유아기에 멸망이 시작된다
  3. **성인기부터 (18세)**: 성인이 될 때까지 성장한 뒤 멸망이 시작된다

## 게임 플레이 화면에 보이는 것
- 위 막대: 나이/멸망 경과 + **허기 · 돈** (이 두 가지만). 허기는 0~100, 높을수록 배고픔이고 가득 차면 위험하다. (식량 수치는 쓰지 않음 — 먹을 것은 가방의 물건이고, 먹으면 허기가 줄어든다)
- 왼쪽 레일 **급소**: 머리 · 목 · 심장 · 장기 · 척추의 변이/손상 배지만 보여 준다. 누르면 **몸 상태 화면**(급소 상세 + 전체 몸 부위, 심장·장기·뼈 포함)이 열린다.
- 오른쪽 레일 **가방**: 선택·진행에서 얻은 물건. 누르면 **인벤토리**가 열리고, 물건을 골라 장비·사용·버리기를 한다. (새로 얻은 물건은 표시)
- 가운데 무대: 장면 + 글, 아래 선택창. 전투에서는 공격 대상이 무대 안에 나온다.

## 인벤토리
- 장비 칸: 무기 / 이식형 무기 / 대체형 무기(몸에 붙은 의수 등)
- 물건 종류: 장비(무기·이식형) / 소모(통조림·붕대…) / 재료(부품…) / 기타(열쇠…)
- 얻은 물건은 선택지 조건에도 쓰인다 (예: 열쇠로 보관함 열기)

## 세계관 정리 (별도 페이지)
- 게임 화면 시안과 **분리**된 [세계관 노트](../world/index.html)로 관리한다. (게임 안의 기능이 아님)
- 작업 방식: 사용자가 **핵심**(큰 줄기·다층 스토리의 씨앗)을 주면 Claude가 **첨언**(덧붙인 아이디어)을 달아 정리하고, 마음에 안 드는 부분은 바꾼다.
- 줄(항목)을 누르면 열린다. 각 줄은 핵심 / 첨언 / 열린 질문 / 이어지는 줄로 구성된다. 데이터는 `world/data.js`.

## 세계관
- 아포칼립스 + 사이버펑크(?)
- **장비**: 무기 / 이식형 무기 / 대체형 무기
- **변이**: 침식 / 감염 / 대체 / 창조 (+ 변이 안 한 상태 = 원본). **모든 신체 부위, 뼈 포함.**
- **몬스터**: 고블린·트롤·오크 같은 기본 몬스터에서 시작해 새로운 몬스터를 계속 추가
  - 몬스터를 관리하는 **관리용 사이트**를 따로 만들면 좋음
- **신체** (변이·대체 가능, 부위별 상태를 따로 가짐)
  - 얼굴: 왼눈 / 오른눈 / 코 / 입 / 귀
  - 몸통
  - **심장 · 장기**: 심장 / 폐 / 위 / 간 / 신장 / 장
  - **뼈**: 두개골 / 척추 / 갈비뼈 / 팔뼈(좌·우) / 다리뼈(좌·우) / 손발뼈
  - 팔(왼·오른 따로): 손 / 팔
  - 다리(왼·오른 따로): 발 / 다리
- **숨김(히든)**: 성기 등 민감한 부위는 **화면 어디에도 표시하지 않는다.** 데이터·조건에서만 존재 가능하고, UI와 사전에는 노출하지 않음. (가슴 크기 설정도 화면에서 뺐음)

## 전투
- **실시간 턴제**: 타이머가 흐르고, 그 안에 공격 방식을 골라야 한다. 못 고르면 그 사이 공격당한다.
- 주인공이 있으면 주위의 적이 공격할 수 있다 (주변 적 모두가 후보, 공격 대상은 무대에서 고른다).
- 공격 방식은 장비 종류와 연결: 근접(무기) / 이식형 / 대체형 + 방어·회피·물건
- 신체 상태가 전투에 영향 (다리 변이는 회피, 팔 대체는 대체형 공격, 심장·장기·뼈는 생존·내구)

## 선택과 특성
- 선택지는 신체·특성에 따라 열리거나 잠긴다. (예: 대체한 팔이 있어야 단말기 사용 가능)
- 태어날 때 환경(집안 형편 등)과 타고난 특성이 정해지고, 살면서 늘거나 바뀐다.

## 시작 (태어나기) — 기본 / 커스텀
**기본 탭** (빠르게 시작)
- 이름 / 성별: **여 · 남 · 랜덤** (랜덤이면 시드로 정해짐) / 멸망 시작 시기
- 태어날 지역: **기본은 랜덤** (여기서는 고를 수 없음)
- **시드**: 같은 시드 = 같은 지역·집안·사건·분기. 정해진 이벤트와 분기를 따라가는 "이야기 시드"도 가능. 저장 칸과 태어나기 화면에 시드를 표시하고 복사·공유.

**커스텀 탭** (세부 사항 + 타고난 특성을 한 곳에)
- **태어날 지역**: 랜덤 / 지정. 다녀간 지역은 **사전(지역 탭)에 기록**되고, 지정은 **새 창("지역 찾기")에서 사전의 지역을 검색해 담는** 방식으로 확정 출생. 집안은 계속 랜덤.
- **부모**(구성 · 몸 상태) / **형제** / **집안 형편** / **시작 허기·돈** — 기본값은 모두 랜덤, 값을 정하면 시드보다 우선.
  - 구성에서 **한 분만 남는 경우**, 어느 분이 남을지는 랜덤.
  - **형제**: 명수는 정할 수 있어도 나보다 **손위인지 손아래인지, 몇째인지는 모른다**(랜덤).
- **타고난 특성**: **기본 특성**(처음부터 사용 가능) 외의 특성은 **랜덤으로 살며 겪어서 사전에 기록된 것만** 쓸 수 있다. **긍정(+)** / **부정(−)** 으로 나눈다.
  - **직접 선택**은 **새 창("특성 고르기")**에서 하고, 기본 / 긍정 목록 / 부정 목록 세 탭에서 따로 골라 넣는다.
  - **고르는 데에는 제한이 없다.** 대신 **점수(긍정 +, 부정 −)가 2 이하**일 때만 플레이를 시작할 수 있다. 그래서 좋은 특성을 더 가져가려면 부정 특성도 들고 가야 한다.
  - **랜덤**으로 시작하면 점수와 상관없이 시작할 수 있다.
- **타고난 몸**: 모두 원본으로 시작.

## 정해야 할 것 (열린 질문)
1. "테스트 기반 게임"은 **텍스트 기반**으로 이해했음. 맞는지?
2. 사전·저장: 브라우저 저장소(IndexedDB) + 내보내기/가져오기 파일로 갈지, 서버를 둘지.
   - 브라우저 저장만 쓰면 기기를 바꾸거나 브라우저 데이터를 지울 때 사라짐 → 내보내기 백업을 기본 기능으로.
3. 몬스터/장비 데이터는 JSON 파일로 두고 관리용 사이트가 그 JSON을 편집하는 구조가 단순함.
4. 사건이 없는 달을 넘기는 기준: 사건이 얼마나 자주 일어나게 할지(평균 몇 달에 한 번), 위험한 시기(멸망 직후 등)에는 더 자주 멈출지.
5. 허기·돈 외에 행복/관계 같은 수치를 둘지 (지금은 몸 상태 배지로만 표현).
6. 허기가 가득 찼을 때의 규칙 (몸 부위 손상으로 이어질지, 바로 사망인지).
7. 어린 나이 등장인물이 나오는 장면의 표현 수위 기준.
